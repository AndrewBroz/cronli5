# 重複發生的時間，繁體中文怎麼寫

這份指南寫給撰寫螢幕文案的人。讀者看到的只有一行字，看一遍就要知道事情什麼時候發生。以下以臺灣的寫法為主軸，香港、澳門不同之處逐項標出，中國大陸的用語另列一節。

例子的來歷用記號標明：

- 〔出處〕：這次查到的真實用例，來源列在文末，引文照錄原來的標點和數字寫法。
- 〔常見〕：我在臺灣（或香港）的招牌、時刻表、公告、App 上反覆看到的寫法，這次沒有逐字核對某一個出處。
- 〔自擬〕：我按本地習慣自己寫的句子。
- 〔記憶〕：憑我對法規或手冊條文的記憶，這次沒能打開原文核對，引用前請再查。

## 一、讀者腦中的單位和歸類

### 1. 一週：不是「weekday／weekend」，是「平日／假日」

臺灣人看時刻表，第一個問題是「今天算平日還是假日」，不是「今天星期幾」。

- **平日**（捷運寫「平常日」）：要上班上課的日子。
- **假日**（交通業寫「例假日」）：週六、週日，加上國定假日。

臺北捷運的定義寫得最清楚〔出處：臺北捷運〕：

> 1. 平常日（週一至週五）
> 2. 例假日（週六、週日及國定假日）

要注意三件事：

1. **「平日」是按「要不要上班」分的，不是按星期幾分的。** 國定假日落在週三，那天是假日；補班的週六，那天是上班日。所以「平日」和「週一至週五」不是同義詞。前者自動扣掉國定假日，後者只是曆面上的五天。英語的 weekday 沒有這層意思，直接對譯會出錯。作者要先想清楚自己指的是哪一個：
   - 純按星期：寫「週一至週五」。
   - 按上班日：寫「平日」或「上班日」，必要時加「（國定假日除外）」讓人不必猜。
2. **補班、補假、調整放假是臺灣一週的一部分。**
   - 國定假日遇到週六、週日，會在前後的上班日「補假」。
   - 過去為了湊連假，會把夾在中間的上班日「調整放假」，再找一個週六「補行上班」（口語叫「補班」，學校叫「補課」）。例如〔出處：人事行政總處公告的報導〕：「農曆除夕前一日(1月27日)適逢星期一,調整為放假日,於2月8日(星期六)補行上班」。近年補班已大幅減少，同一批報導提到 115 年沒有調整放假和補行上班。
   - 每年哪幾天放假，以行政院人事行政總處公布的「政府行政機關辦公日曆表」為準；民間企業另依勞動部的規定，不一定相同。
   - 另有臨時的「停止上班上課」（颱風假），由各縣市政府當天宣布，任何固定的文案都預料不到。
3. **「例假日」有兩個意思。** 交通、商家說的「例假日」是週六、週日加國定假日；《勞動基準法》裡的「例假」是每七天中的一天。螢幕文案用前一個意思，但不要在談勞動條件的文字裡混用。

其他常用的歸類：

| 說法 | 指什麼 | 備註 |
|---|---|---|
| 週末 | 週六、週日 | 口語也含週五晚上 |
| 週休二日 | 週六、週日不上班 | 制度名稱，也拿來指那兩天 |
| 連假、連續假期 | 三天以上連著放 | |
| 國定假日 | 法定放假的節日 | 香港叫「公眾假期」，見第八節 |
| 工作天、工作日 | 計算辦理天數用 | 「7個工作天內寄出」；不拿來說「每個平日」 |

**一週從哪天開始？** 語言上星期一是「一」，所以區間一律「週一至週日」，沒有人寫「週日至週六」。但臺灣印的月曆多半把星期日排在最左邊。寫文字時從週一數起；畫月曆時兩種都有人用。

**星期的三套名字：**

- **週一…週日**：最短，表格、時刻表、App 最常用。
- **星期一…星期日**：正式一點，公文、公告、新聞用。
- **禮拜一…禮拜天**：只在口語，不寫進介面。

「星期天」「週日」「星期日」都有人說；書面取「週日」或「星期日」。日期後面的括號縮到一個字：「2/8（六）」「11月19日（四）」。

**「週」不寫成「周」。** 臺灣教育部的標準字體，表示星期的是「週」；「周」留給「周到」「周圍」和姓氏。寫「周一」在臺灣看起來像大陸或香港報紙的文字（見第八、九節）。

**星期用中文數字，不用阿拉伯數字。** 「週一」不寫「週1」，「星期三」不寫「星期3」。這是慣用語，行政院的數字使用原則也把「星期一、週一」列在用中文數字的一類〔記憶〕。

### 2. 一天裡的時段

中文說鐘點，習慣先說時段，再說數字。時段的切法大致如下（界線是約數，各人略有出入）：

| 時段 | 大約 | 例 |
|---|---|---|
| 凌晨 | 0 點到 5 點 | 凌晨2點 |
| 清晨 | 5 點到 6、7 點 | 清晨5點半 |
| 早上 | 6 點到 9、10 點 | 早上7點 |
| 上午 | 到 12 點 | 上午10點 |
| 中午 | 11 點到 13 點 | 中午12點 |
| 下午 | 13 點到 17、18 點 | 下午3點 |
| 傍晚 | 17 點到 19 點 | 傍晚6點 |
| 晚上 | 18 點到 24 點 | 晚上8點 |
| 深夜、半夜 | 23 點以後 | 深夜11點、半夜12點 |

- **正式文字只用「上午／下午」兩分**，再加「中午」「凌晨」。「早上」「晚上」「傍晚」是日常說法，App 的提醒可以用，公告少用。
- **時段在前，數字在後**：「下午3:30」。寫成「3:30 下午」是翻譯腔。臺灣店家即使用英文縮寫也照中文語序放在前面：「AM 11:00～PM 9:00」〔常見〕。
- 手機系統的 12 小時制只分「上午」「下午」，所以會出現「下午11:30」「上午12:05」。這是系統的寫法，不是人的寫法；人會寫「晚上11:30」「凌晨12:05」或直接用 24 小時制。

交通另有自己的時段：**尖峰／離峰**。臺北捷運〔出處〕：

> (1) 尖峰時段（07:00～09:00，17:00～19:30）：約2～4分鐘。
> (2) 離峰時段：約4～10分鐘。
> (3) 23:00以後：約12分鐘。

### 3. 鐘點

臺灣有三種寫法，各有場合：

| 寫法 | 例 | 場合 |
|---|---|---|
| 24 小時制數字 | 09:00、17:30、23:00 | 時刻表、營業時間、App、表格。最不會錯 |
| 「時、分」 | 上午9時、下午5時30分 | 公文、公告、新聞稿 |
| 「點、分」 | 早上9點、下午5點半 | 口語、App 提醒、親切的文案 |

- **「時」是書面，「點」是口語。** 同一句裡不要混用。
- 整點說「9點整」「上午9時整」。香港寫「9時正」，臺灣不這麼寫。
- 半點說「9點半」。「一刻」「三刻」（15 分、45 分）老一輩聽得懂，現在幾乎沒人寫，直接寫「9點15分」。
- 個位數的分，口語有時加「零」：「9點零5分」。書面寫「9時5分」或「09:05」。
- **「兩」和「二」**：鐘點說「兩點」不說「二點」，但「十二點」。時長說「兩小時」「兩天」「兩週」，不說「二小時」。月份和日期用「二」：「二月」「二日」。寫阿拉伯數字（2點、每2小時、2月）就不必選，讀者自己會唸對，這是數字用阿拉伯數字的一個實際好處。
- **時刻和時長用不同的字。** 時刻：9時15分、9點15分。時長：15分鐘、2小時（口語「兩個鐘頭」）。「15分」只在時刻表式的緊湊寫法裡當時長用（「約2～4分鐘」是常態，但也看得到「尖峰約 1 分 20 秒至 2 分」〔出處：北捷新聞稿的報導〕）。
- **24:00 在臺灣是通用的結束時刻**：「營運時間：06:00～24:00」〔出處：臺北捷運〕。開始時刻用 00:00。跨過午夜的結束時刻寫「02:00」「凌晨2:00」或「翌日02:00」；日本式的「26:00」臺灣一般讀者不習慣。
- 冒號用半形「:」，前後不空格。時、分各兩位（09:05），時刻表裡個位數的時也補零。

### 4. 秒

需要到秒的時候：

- 時刻：「9時15分30秒」或「09:15:30」。
- 時長和間隔：「每30秒」「1分20秒」。
- 「整分」「整點」表示秒數、分數為零：「每分鐘整」不太有人說，會說「每分鐘一次」；要指明是哪一秒，說「每分鐘的第30秒」〔自擬〕。

### 5. 日期

- **順序永遠由大到小：年、月、日，然後星期，然後時段和鐘點。** 「115年2月8日（星期六）上午9時」。這個順序沒有例外，也是和英語最大的不同之一。
- 數字寫法：「2026/11/19」「11/19」「11月19日」。斜線式在臺灣一律是月在前、日在後。**香港相反**（見第八節）。
- 月裡的日子，書面寫「日」，口語說「號」：「每月5日」／「每個月5號」。介面用「日」。
- 月份只有數字名：1月到12月。沒有 January 那樣的專名，所以列舉月份很短：「1、4、7、10月」。
- **旬**：上旬（1–10日）、中旬（11–20日）、下旬（21日到月底）。英語沒有對應的詞。另有「月初」「月中」「月底」，都是約略的說法，不能當精確時間用。
- **大月、小月**：31 天的月份叫大月，其餘叫小月。寫「每月31日」的人，要知道小月沒有這一天。
- **單月、雙月**：1、3、5…月是單月（也叫奇數月），2、4、6…月是雙月。統一發票「每逢單月25日開獎」是人人知道的例子〔常見〕。
- **農曆**：民俗、市集、宗教活動按農曆走：「每逢農曆初一、十五」。農曆的日子用中文數字和「初」字（初一、初五、十五、廿三），不寫「農曆1日」。公文的數字原則也把「正月初五」列在中文數字一類〔記憶〕。

### 6. 年：民國和西元各管一邊

- **民國紀年**用在政府和跟政府打交道的地方：公文、法規、稅單、統一發票、駕照、健保、學年度、銀行存摺、會計年度。「民國115年」「115年度」「115/11/19」。
- **西元紀年**用在交通訂票、電商、科技產品、國際往來、多數 App。「2026年」「2026/11/19」。「西元」是臺灣的說法；大陸說「公元」，香港兩種都有。
- 民國年加 1911 得西元年：115 + 1911 = 2026。
- **歧義**：兩、三位數的年份脫離上下文就看不懂。「15年」可能是民國 15 年、2015 年，也可能是「十五年間」。嚴謹的寫法：民國年要嘛帶「民國」，要嘛出現在全篇都用民國的文件裡；面向一般大眾的介面用四位數的西元年。同一個畫面不要兩種並用。

## 二、資訊的順序

中文的規則只有一條：**由大到小，範圍在前，事情在後。**

> 哪些年、哪些月 → 哪些日／星期幾 → 時段 → 幾點幾分 → 多久一次 → 做什麼

〔自擬〕

- 每年1月1日凌晨0點
- 每月1日、15日上午9:00
- 每週一至週五 08:00～18:00，每30分鐘一班
- 平日 07:00～09:00，約2～4分鐘一班

幾點說明：

- **時間詞放在動詞前面。**「每週一上午9點開會」，不是「開會在每週一上午9點」。
- **時間前面通常不加「在」「於」。**「每天9點」就夠了。「在每天的9點」是翻譯腔；「於每日9時」是公文腔。
- **頻率的句式是「每＋間隔＋（動詞）＋一次／一班」。**「每15分鐘一班」「每2小時執行一次」「每天備份一次」。句尾的「一次」「一班」是中文的習慣，省掉也通，但加上去句子才站得穩。
- **表格和招牌用「主題＋空格或冒號＋時間」**，不必成句：

  > 營運時間：06:00～24:00〔出處：臺北捷運〕
  >
  > 週一至週五 11:00～21:30〔常見〕

- **例外放最後**，多半用括號或另起一句：「（國定假日除外）」「週三公休」。

## 三、頻率

### 1. 基本說法

| 意思 | 自然的寫法 | 不自然 |
|---|---|---|
| 每天 | 每天（口語、App）／每日（書面） | 每一天、每1天 |
| 每小時 | 每小時 | 每一個小時、每1小時 |
| 每分鐘 | 每分鐘 | 每1分鐘 |
| 每 15 分鐘 | 每15分鐘 | 每一刻鐘 |
| 每 30 分鐘 | 每30分鐘／每半小時 | 每0.5小時 |
| 每 90 分鐘 | 每90分鐘／每一個半小時 | 每1.5小時 |
| 每兩小時 | 每2小時／每兩小時 | 每二小時 |
| 每週 | 每週 | 每一週 |
| 每月 | 每月／每個月 | |
| 每年 | 每年 | |
| 每週的某天 | 每週一、每週二及週四 | 在每個星期一 |
| 每月的某天 | 每月5日 | 每月的第5天 |
| 每月的第幾個星期幾 | 每月第2個週二／每月第二週星期二 | 每第二個星期二 |
| 每月最後一天 | 每月最後一天／每月月底 | |

間隔是「一」的時候，數字不寫：「每天」「每小時」，不寫「每1天」。

**「逢」和「每逢」** 是中文特有的重複標記，意思是「每次碰到」：「每逢單月25日」「逢週一休館」「逢週六、日加開」〔出處：交通部門公告的報導，原文作「逢週六、日加開」〕。它比「每」多一層「遇到這種日子就…」的意思，特別適合說例外和加開。臺灣書面常用，口語少用；香港用得更多（見第八節）。

### 2. 一小時裡的哪幾分

- **整點**：分數為零。「每小時整點」「每逢整點」「整點發車」。
- **半點**：30 分。「整點及半點各一班」。
- 其他的分：「每小時的15分、45分」「每小時05分、35分發車」〔常見於客運站牌〕。

口語和招牌都接受這種寫法。「每小時的第15分鐘」比較像翻譯。

### 3. 一天幾次

次數少的時候直接列出鐘點：「每天 08:00、12:00、18:00」。也可以先說次數：「每天三次：08:00、12:00、18:00」。藥袋上的「一天三次」「每6小時一次」是大家最熟的頻率文字〔常見〕。

### 4. 隔：最容易出錯的字

- **隔天、隔日**：有兩個意思。一是「每隔一天」（隔日一次），一是「第二天」（隔日配達、隔天早上）。「隔日 06:00」會被讀成「第二天早上6點」。要說每兩天一次，寫「每兩天一次」。
- **每隔兩天**：有人理解成每三天一次（中間空兩天），有人理解成每兩天一次。不要用。寫「每3天一次」，或直接說日期。
- **隔週**：「隔週六」「隔週看診」是真實用法〔出處：健保巡迴醫療表有「(隔週)」的標注〕，意思是兩週一次。但讀者不知道是哪一週，所以醫療院所多半改寫成「每月第二週、第四週星期六」〔出處：基隆市巡迴醫療表作「每月第二週星期六」〕。這是嚴謹作者的標準解法：**用可以對月曆的說法取代「隔」。**
- **單數日、雙數日**（單號、雙號）：按日期的奇偶。「單數日收一般垃圾」這類寫法存在，但月底 31 日接 1 日會連續兩天單數，寫的人要知道。
- **雙週**：「雙週刊」是兩週一次。「雙週」單獨當頻率用，不如「每兩週」清楚。

### 5. 「每週一」和「每週一次」

「每週一」是每個星期一；「每週一次」是一週一回。前三個字一樣，讀者讀到第四個字才知道是哪一個。同樣的還有「每月一日」和「每月一次」。解法：

- 日期用阿拉伯數字：「每月1日」。
- 星期後面馬上接時間或動詞，不要接「次」：「每週一上午9點」。
- 說次數時寫「每週1次」或「一週一次」。

### 6. 不整除的間隔

「每7分鐘」這種說法，中文讀者會理解成每一班都隔 7 分鐘。如果實際上每小時重新從整點算起，最後一段不足 7 分鐘，這句話就是錯的。交通業遇到不規則的班次不說間隔，直接列時刻，或者說「約」：「約4～10分鐘」〔出處：臺北捷運〕。「約」字在臺灣的班距說明裡幾乎是固定的，它明白告訴讀者這不是精確的節拍。

## 四、時間區間，以及頭尾算不算

### 1. 連接的字和符號

| 寫法 | 例 | 場合 |
|---|---|---|
| ～ | 06:00～24:00 | 臺灣最常見；時刻表、營業時間、公告 |
| 至 | 週一至週五、上午9時至下午5時 | 書面、正式 |
| 到 | 週一到週五、9點到5點 | 口語、親切的文案 |
| - 或 – | 9:00-12:00、7:30-10:30 | 表格、醫院門診表、App；省空間 |
| 自…起至…止 | 自即日起至12月31日止 | 公文、活動辦法 |

- 「～」（全形波浪號）是教育部《重訂標點符號手冊》修訂版裡連接號的乙式；甲式是「—」。手冊說兩式可自由選用〔出處：搜尋結果引手冊「本修訂版標點符號有甲、乙式者，可自由選用」〕。實際上臺灣表示時間起止幾乎都用「～」，因為「—」容易和破折號、中文數字「一」混淆。
- 一個區間裡，兩端的寫法要對稱：「09:00～17:00」，不要「9點～17:00」。
- 用「至」「到」時，共同的部分可以省：「上午9時至11時」「1日至5日」「週一至五」（香港常省成這樣；臺灣多半兩端都寫全，「週一至週五」）。
- 「從」可有可無：「從週一到週五」＝「週一到週五」。招牌一律不加。

### 2. 日子的區間：兩頭都算

「週一至週五」包含週一和週五。「1日至5日」包含 1 日和 5 日。「1月至3月」包含整個 3 月。中文讀者對此沒有疑問，不必加註。

### 3. 鐘點的區間：結束點是一個時刻

「09:00～17:00」表示 17:00 結束。疑問出在「區間裡每隔一段時間發生一次」的時候：17:00 那一次有沒有？中文沒有現成的字能回答，時刻表的解法是**另外寫明頭尾**：

- 「首班車 06:00，末班車 24:00」（公車業也說「頭末班車」）。
- 「最後入場 16:30」「最後點餐 20:30」「收件至17:00止」〔常見〕。

也就是說，區間給範圍，「首／末」「最後」給確切的最後一次。兩個都寫，讀者就不用推算。

### 4. 「前」「後」「以前」「以後」含不含當日

這是中文特有的麻煩，也有中文特有的解法。

- 法律上「以上、以下、以內」連本數計算（《刑法》第10條）〔記憶〕，一般人也多半把「5日以前」理解成含 5 日。
- 但光寫「5日前」，有人算 5 日，有人不算。
- 嚴謹的作者加一個括號：「5日（含）前」「5日（含當日）以前」「滿18歲（含）以上」。要排除就寫「（不含）」。「（含）」是臺灣公告裡極常見的寫法〔常見〕，短、準，沒有翻譯腔。
- 「至5日止」「5日截止」含 5 日整天，除非另寫鐘點。寫上鐘點最保險：「5日 23:59 截止」。
- 「超過」「逾」不含本數；「滿」「達」含本數；「未滿」不含。

### 5. 跨過午夜

- 「22:00～翌日06:00」。臺灣「翌日」「隔日」「次日」都有人用：「翌日」最書面，也是臺港共通的；「隔日」最口語（但見上文「隔」的歧義）；「次日」偏公文。
- 商家常省掉「翌日」，直接寫「18:00～02:00」，讀者看得懂，因為結束比開始早。
- **凌晨屬於哪一天**：嚴格說「週六凌晨1點」是週六剛開始的那個 1 點。但口語裡「週五晚上到凌晨」的凌晨，很多人仍當成週五的夜。只說「週六凌晨」一般沒問題；真的怕錯，寫「週六 01:00（週五深夜）」〔自擬〕。

### 6. 12 點

- 「中午12點」「凌晨12點」「半夜12點」「午夜12點」都清楚。
- 「上午12時」「下午12時」**不要寫**，讀者各有各的理解。
- 最保險是 24 小時制：12:00、00:00、24:00。

## 五、列舉

- **頓號「、」** 是中文列舉專用的標點，英語沒有對應物。並列的時間一律用頓號，不用逗號：「每週一、三、五」「08:00、12:00、18:00」。
- **共同的字只說一次。** 這是中文列舉最省力的地方：
  - 「週一、三、五」（不必「週一、週三、週五」，兩種都對，前者更短）
  - 「每月5、15、25日」
  - 「1、4、7、10月」
  - 「每月第二、四週的星期六」
  - 口語甚至不停頓：「每週一三五」「二四六」。
- **最後一項前面可以加「及」「和」「與」，也可以不加。**「週六、週日及國定假日」〔出處：臺北捷運〕。「及」「與」書面，「和」「跟」口語。加了連接詞，前面仍用頓號，不加逗號。
- 列舉超過四、五項，讀者記不住。這時中文作者會反過來說：把「週一、二、四、五、六」改說「週三、週日停收」。兩種寫法在垃圾清運的公告上都真實存在〔出處：新竹市垃圾清運資料的整理文作「每週一、二、四、五、六」及「週三和週日休息」〕。
- 日期帶星期，用括號：「2/8（六）」「2月8日（星期六）」〔出處：補班公告的報導〕。括號用全形。

## 六、例外

中文說例外，習慣把它放在後面，而且各行各業有自己的動詞。選對動詞，句子就短。

| 行業 | 不做的那天 | 例 |
|---|---|---|
| 商店、餐廳 | 公休、店休 | 週二公休／每週二公休 |
| 博物館、圖書館 | 休館 | 每週一休館 |
| 診所、醫院 | 休診 | 週日休診 |
| 火車、公車 | 停駛 | 例假日停駛 |
| 垃圾車 | 停收 | 週三、週日停收 |
| 機關 | 不上班、不受理 | 例假日不受理 |
| 排程、系統 | 不執行、暫停 | 國定假日不執行 |

通用的框架：

1. **括號加「除外」**：「每天 09:00～17:00（週三除外）」「週一至週六（國定假日除外）」。最通用，介面文案首選。
2. **「除…外」**：「除週三外，每天 09:00～17:00」。書面，稍重。
3. **「不含」**：用在計數和區間。「每月1日至5日（不含假日）」。
4. **另起一句說休息日**：「11:00～21:00，週二公休」。招牌最常見。
5. **「遇…」說條件**，後面接處置：
   - 「遇國定假日照常開放」
   - 「遇假日順延」（延到下一個上班日）
   - 「遇假日提前」「遇颱風停駛」
   - 博物館的真實寫法〔出處：國立臺灣博物館開放資訊的整理文〕：「每週一、除夕及春節初一休館,逢國定假日及連續假期均照常開館」。

   「遇／逢…則…」是中文說「例外的例外」最簡潔的句式，英語要用一整個從句。

翻譯腔的寫法：「除了星期三以外的每一天」「每天，但不包括星期三」。能通，但比「每天（週三除外）」長一倍，而且沒有人這樣寫招牌。

**一個基準加一個例外**，讀者記得住；兩個以上的例外，改成正面列舉通常更好。

## 七、「兩類日子中的任何一類」，和「兩個條件都符合」

這兩件事中文用不同的字，嚴謹的作者不會混。

### 1. 任何一類（聯集）

用「及」「和」「以及」「或」，或者只用頓號：

- 「週六、週日及國定假日」〔出處：臺北捷運〕。這是全臺灣最熟悉的聯集句式：屬於其中任何一類的日子都算。
- 「每月1日、15日，以及每週一」〔自擬〕
- 「每週五和每月最後一天」〔自擬〕

寫的時候注意：

- 兩類日子性質不同（一類是日期、一類是星期）時，**各自帶上自己的「每月」「每週」**，中間用「，以及」或「及」隔開。「每月15日及每週五」清楚；「每月15日週五」就變成另一個意思了。
- 「或」也表示任何一類（「週六或假日」），但放在排程文字裡，有人會讀成「二者擇一」。「及」「以及」比較穩。

### 2. 兩個條件都符合（交集）

用「的」、「且」、「適逢」、「遇」，或直接把兩者疊成一個名詞：

- 「每月第一個週一」
- 「13日星期五」「適逢星期五的13日」
- 「每月15日，遇週五時」
- 「1月的每個週一」「每年1月每週一」

直接疊在一起、中間沒有頓號或連接詞，讀者就當成交集：「1月週一」是 1 月裡的週一。**有沒有頓號或「及」，就是聯集和交集的分界。** 所以這個標點不能省，也不能多。

## 八、香港和澳門

先說結論：**差別主要在字詞和記號，句子的骨架相同。** 順序（由大到小）、頓號列舉、「至」表區間、括號加「除外」、「逢…」說例外，港澳和臺灣完全一樣。但有幾處不只是換字：一週的分法、斜線日期的順序、12 小時制為主，這三項會改變整行字的樣子。

### 香港

| 項目 | 臺灣 | 香港 | 差別的性質 |
|---|---|---|---|
| 星期 | 週一（最常用）、星期一 | **星期一**（正式文字的主流）；報紙寫「周一」（不帶辶） | 字詞 |
| 省略式 | 週一至週五 | 星期一至五 | 字詞 |
| 法定放假日 | 國定假日 | **公眾假期**（俗稱「紅日」）；另有僱傭條例的「法定假日」（俗稱勞工假），日數較少 | 字詞和制度 |
| 一週的分法 | 兩分：平日／假日 | **常三分**：星期一至五／星期六／星期日及公眾假期 | **結構不同** |
| 鐘點 | 24 小時制為主；文字用「時」或「點」 | **12 小時制加「上午／下午」為主**：上午9時至下午5時 | **整行不同** |
| 整點 | 9點整、9時整 | 9時**正** | 字詞 |
| 12 點 | 中午12點、午夜12點 | **正午**12時、午夜12時 | 字詞 |
| 斜線日期 | 年/月/日、月/日：11/19 | **日/月/年**：19/11/2026 | **順序相反，會誤讀** |
| 班次 | 班距約6分鐘；每6分鐘一班 | 約6分鐘**一班車**；「班次」 | 字詞 |
| 尖峰 | 尖峰／離峰 | **繁忙時間／非繁忙時間** | 字詞 |
| 頭尾班 | 首班車／末班車 | **頭班車／尾班車** | 字詞 |
| 不開 | 停駛、公休 | **不設服務**、休息 | 字詞 |
| 每逢 | 每週六、日 | **逢**星期六、日（「逢」用得比臺灣多） | 字詞 |
| 第二天 | 翌日、隔日、次日 | 翌日 | 字詞 |
| 紀年 | 民國、西元 | 公元（只有一種，不必區分） | 制度 |

真實用例：

- 港鐵新聞稿〔出處〕：「逢星期六、星期日及公眾假期的上午十時至正午十二時，以及傍晚五時至七時的列車班次，將由約 7 分鐘加密至約 6.5 分鐘一班車」。這一句裡可以看到：「逢」、三類日子的聯集、中文數字寫鐘點（港鐵和報紙的習慣）、「正午」、「傍晚」當正式時段、「一班車」。
- 港鐵〔出處〕：「星期六、日、學校假期及公眾假期不設服務」。
- 運輸署文件〔出處〕：「星期一至六(公眾假期除外)」「首班車時間改為上午11時30分」「加密至每15至20分鐘一班」。香港政府文件用阿拉伯數字寫鐘點，這點和港鐵不同。
- 香港天文台〔出處〕的辦公時間按「星期一至五」列出，鐘點作「上午9時至下午4時45分」一類。

說明：

- **星期六在香港常自成一類。** 不少機構星期六上午辦公，交通班次也另有一套，所以時間表常是三欄。把臺灣的「平日／假日」兩分直接搬過去，星期六就沒有著落。
- **星期日本身在法律上就是公眾假期**〔記憶：《公眾假期條例》〕，但文字上仍習慣寫「星期日及公眾假期」，沒有人覺得重複。
- 香港政府公文的寫法，以公務員事務局法定語文事務部的《政府公文寫作手冊》為準〔記憶〕；標點和字形沒有像臺灣教育部那樣的單一規範，各機構自有體例。
- 香港沒有「補班」。公眾假期遇星期日則順延補假，但不會把星期六改成上班日。
- 惡劣天氣的臨時安排是「八號烈風或暴風信號」「黑色暴雨警告」生效時的安排，相當於臺灣的停止上班上課。
- 口語粵語的說法（「禮拜」「晏晝」「三點九」「一個字」）不進入書面，介面文案不用。

### 澳門

- 用詞大體同香港：**公眾假期**、「星期一至星期五」；「週一至週五」也看得到。勞動法另有「強制性假日」。
- 鐘點：政府文字用「時、分」加上午下午。《澳門特別行政區公報》裡的批示用中文數字寫全：「星期一至星期四：上午八時三十分至下午二時三十分」〔出處〕、「下午五時四十五分，星期五則自…」〔出處，片段〕。
- 公共部門的辦公時間星期五比星期一至四早一點下班〔記憶〕，所以澳門的時間表常把「星期一至四」和「星期五」分開寫。這又是一個本地的一週分法。
- 斜線日期同香港，日在前。
- 澳門的正式文字受葡文法律文本影響，句子較長、較硬；面向大眾的文案則和香港相近。

## 九、中國大陸的用語：臺灣、香港讀者會覺得不像本地文字的

以下不是換成繁體字就能用的。

| 大陸用語 | 臺灣 | 香港 |
|---|---|---|
| 周一（周） | 週一 | 星期一；報紙也用「周」 |
| 工作日（指週一到週五） | 平日、上班日 | 星期一至五、工作天 |
| 节假日、法定节假日 | 國定假日、例假日 | 公眾假期 |
| 调休 | 補班、補假、調整放假 | （無此制度） |
| 双休日 | 週休二日、週末 | 周末 |
| 早高峰、晚高峰、平峰 | 尖峰、離峰 | 繁忙時間、非繁忙時間 |
| 首班车／末班车 | 首班車／末班車（同） | 頭班車／尾班車 |
| 发车间隔、班次间隔 | 班距 | 班次 |
| 一趟（每10分钟一趟） | 一班 | 一班 |
| 晚8点、早7点（省「上」字） | 晚上8點、早上7點 | 晚上8時 |
| 公历、公元 | 國曆、西元 | 公曆、公元 |
| 星期天 | 星期日、週日（「星期天」口語也說） | 星期日 |
| 次日 | 翌日、隔日（「次日」偏公文） | 翌日 |
| 全天、全天候 | 全天、全日、24小時 | 全日、24小時 |
| 营业时间 9:00—18:00（一字线） | 09:00～18:00 | 上午9時至下午6時 |

- 大陸的標點和數字另有國家標準（《標點符號用法》和《出版物上數字用法》）〔記憶〕，時間起止用一字線「—」。臺灣用「～」。這是記號的差別，但一眼就看得出來。
- 大陸的「工作日」是日常用語（「工作日 9:00—18:00」）。臺灣說「工作日」「工作天」多半是在數天數（「3個工作天」），拿來當「平日」用會顯得是對岸的文字。
- 「调休」在臺灣、香港都不通。臺灣說「補班」「補假」；香港沒有這回事。
- 相同的也很多：每天、每小時、每月5日、上午／下午、凌晨、頓號列舉、「至」表區間、「除外」，三地都通。差別集中在**跟制度有關的詞**（假日、工作日、紀年）和**交通業的術語**。

## 十、有歧義的說法，和嚴謹作者的解法

| 有歧義的寫法 | 可能的讀法 | 解法 |
|---|---|---|
| 每天8點 | 早上或晚上 | 08:00、早上8點、晚上8點 |
| 上午12時、下午12時 | 中午或午夜 | 中午12點、00:00、24:00 |
| 每隔兩天 | 每兩天或每三天 | 每3天一次；或列日期 |
| 隔日、隔天 | 每兩天一次，或第二天 | 每兩天一次／翌日 |
| 隔週六 | 不知是哪一週 | 每月第二、四週星期六 |
| 每週一… | 每個星期一，或每週一次 | 每週一上午…／每週1次 |
| 每月一日 | 每月 1 日，或「每月一天」 | 每月1日 |
| 5日前 | 含不含 5 日 | 5日（含）前；5日 23:59 截止 |
| 9:00～17:00 每小時 | 17:00 有沒有 | 另寫「末班 17:00」 |
| 週一至週五 | 遇國定假日算不算 | 平日；或加（國定假日除外） |
| 平日 | 補班日算不算 | 平日（含補班日）；或逐日列出 |
| 月底 | 最後一天，或最後幾天 | 每月最後一天 |
| 每月31日 | 小月怎麼辦 | 每月最後一天；或註明小月不適用 |
| 15年、115/3/5 | 民國或西元 | 四位數西元年；或寫「民國」 |
| 3/4 | 臺灣讀 3 月 4 日，香港讀 4 月 3 日 | 3月4日 |
| 週六凌晨 | 週五深夜過後，或週六深夜過後 | 週六 01:00 |
| 每7分鐘 | 是否每班都隔 7 分鐘 | 列時刻；或「約7分鐘」 |
| 每月15日和週五 | 聯集，或「是週五的 15 日」 | 每月15日，以及每週五／適逢週五的15日 |

共同的原則：**能寫成讀者可以對照時鐘或月曆的東西，就不要讓讀者推算。**

## 十一、自然、公文腔、翻譯腔

同一件事的三種寫法〔自擬〕：

| 自然 | 公文腔 | 翻譯腔 |
|---|---|---|
| 每週一上午9點 | 於每週一上午9時整 | 在每個星期一的上午9點鐘 |
| 平日 09:00～18:00 | 自週一起至週五止，每日上午9時至下午6時 | 在週一和週五之間，從9點到18點 |
| 每15分鐘一班 | 班距為15分鐘 | 每15分鐘發生一次 |
| 每天（週三除外） | 除週三外，每日均… | 除了星期三以外的每一天 |
| 每月1日、15日 | 每月1日及15日各1次 | 在每個月的第1天和第15天 |
| 每小時整點 | 每小時整點時 | 在每個小時的第0分鐘 |
| 每年1、4、7、10月的1日 | 每年1月、4月、7月及10月之1日 | 在1月、4月、7月和10月的第一天 |
| 週六、週日及國定假日 | 例假日及國定假日 | 在週末和公眾假日 |
| 即日起 | 自即日起 | 從現在開始 |

**公文腔的標記**：於、自…起至…止、迄、均、各、之、逢…順延、每日（在口語場合）、…整（不必要時）。公告、法規裡這樣寫是本分；放進 App 就顯得冷。

**翻譯腔的標記**：

- 時間前面加「在」，後面加「的」：「在每天的9點」。
- 「每一個」「每1個」：中文說「每」就夠了。
- 「第 N 天」「第 N 分鐘」取代「N 日」「N 分」。
- 「在 A 和 B 之間」取代「A 至 B」。
- 「每工作日」「每個工作日」取代「平日」。
- 「發生」「觸發」「運行」當萬用動詞。中文會選具體的動詞（開、發車、執行、提醒、備份），或乾脆不用動詞。
- 時段放在數字後面：「9:00 上午」。
- 「午夜」到處用。臺灣人日常說「半夜12點」「凌晨12點」，「午夜」帶文藝氣；香港的「午夜12時」則是正式寫法。
- 逐字照搬英語的列舉連接：「週一，週三，和週五」。中文是「週一、三、五」。

**英語自然而中文不自然的東西**：

- weekday／weekend 的二分（中文是平日／假日，按上班與否）。
- AM/PM 後置。
- 月份專名、序數日（the 1st）：中文只有數字。
- 「every other」：中文的「隔」有歧義，作者寧可改寫。
- 「on the hour」：中文有更短的「整點」。
- 「noon／midnight」：中文有「中午」，但「午夜」不如 midnight 日常。
- 「fortnight」「biweekly」：沒有對應的常用詞，說「每兩週」。

**中文有而英語沒有的東西**：

- 頓號，以及列舉時共同成分只說一次（週一、三、五）。
- 「逢／遇…則…」的條件句式（遇假日順延）。
- 「（含）」「（不含）」。
- 上旬、中旬、下旬；大月、小月；單月、雙月；單號、雙號。
- 農曆的日子（初一、十五）和節氣。
- 一天分成七、八個時段，而且時段是鐘點的一部分。
- 各行業現成的「不做」動詞：公休、休館、休診、停駛、停收。
- 民國紀年。
- 「平日」本身就排除了國定假日。

## 十二、用字、標點、數字的規範，以及誰訂的

### 臺灣

| 事項 | 規範 | 機關 |
|---|---|---|
| 數字用阿拉伯數字還是中文數字 | 《公文書橫式書寫數字使用原則》（93年8月17日院臺秘字第0930089122號函）〔出處〕 | 行政院 |
| 公文格式 | 《文書處理手冊》〔記憶〕 | 行政院 |
| 標點符號 | 《重訂標點符號手冊》修訂版〔出處〕 | 教育部 |
| 字形（「週」「臺」） | 國字標準字體〔記憶〕 | 教育部 |
| 哪天放假、哪天補班 | 政府行政機關辦公日曆表；《政府機關調整上班日期處理要點》〔出處〕 | 行政院人事行政總處 |
| 民間的例假、休息日、國定假日 | 《勞動基準法》及相關規定 | 勞動部 |

數字使用原則的要點：

- 日期、時間、序數、編號、統計數字用**阿拉伯數字**〔出處：搜尋結果引原則及其舉例，如日期寫作「民國94年7月8日」一類〕。我記得的舉例還有「7時50分」「延後3週辦理」〔記憶〕。
- 慣用語、專有名詞、描述性用語、概數用**中文數字**：「星期一」「週一」「正月初五」「約三、四天」〔記憶〕。
- 法規條文本身用中文數字〔出處〕。所以法規裡會看到「每年一月一日」，一般公告是「每年1月1日」。

這些規範只拘束公文。民間和介面文案沒有義務遵守，但大體照這個方向走，因為讀者已經習慣了。

實務上的補充：

- **數字用半形。** 全形數字（１２：００）只在直排或舊式招牌出現。
- **中文和數字之間空不空格**，臺灣沒有官方規定。公文不空（「每月5日」）；科技業不少人主張空半形格（「每月 5 日」）。兩種都有人用，同一個產品裡統一即可。本文引用出處時照原文。
- **標點用全形**：，、。：；（）～。鐘點裡的冒號和日期的斜線用半形。
- 「臺」是正式寫法（臺鐵、臺北市），「台」是通行的俗寫（台灣高鐵、台北捷運GO）。專有名稱照對方自己的寫法。

### 香港

- 政府公文：公務員事務局法定語文事務部《政府公文寫作手冊》〔記憶〕。
- 假期：《公眾假期條例》《僱傭條例》〔記憶〕。
- 標點、數字沒有單一的官方標準；政府文件用阿拉伯數字寫鐘點和日期，港鐵和部分報紙用中文數字〔出處，見第八節〕。

### 澳門

- 假期和辦公時間由特區政府以行政命令、批示公布，載於《澳門特別行政區公報》〔出處〕。
- 公報的正式文本用中文數字寫鐘點〔出處〕；面向市民的網頁多用阿拉伯數字〔記憶〕。

## 十三、給文案作者的檢查清單

1. 順序是不是由大到小：年月、日或星期、時段、鐘點、頻率？
2. 讀者能不能直接對時鐘和月曆，不必加減？
3. 鐘點有沒有早晚之分（24 小時制，或帶時段）？
4. 「平日」和「週一至週五」選對了嗎？國定假日、補班日怎麼算，說了嗎？
5. 區間的最後一次算不算，說了嗎？
6. 有沒有用到「隔」「前」「月底」「上午12時」這些會分歧的字？
7. 並列用的是頓號嗎？共同的字是不是只說了一次？
8. 兩類日子之間有沒有「及／以及」（任何一類），還是疊在一起（同時符合）？
9. 例外是不是放在最後，用了這一行的現成動詞？
10. 星期是中文數字、其他是阿拉伯數字嗎？「週」有沒有寫成「周」？
11. 有沒有「在…的」「每一個」「第 N 天」這類翻譯腔？
12. 給香港、澳門讀者時：星期、假期名稱、12 小時制、斜線日期都換了嗎？星期六有沒有著落？
